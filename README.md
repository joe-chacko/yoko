# Bob Configuration Branch

This branch contains Bob Shell configuration files that are shared across the team.

## Structure

- `modes/` - Custom Bob Shell modes
- `mcp-servers/` - MCP server configurations
- `settings.json` - Bob Shell settings (if needed)

## Usage

This branch is checked out as a Git worktree in `.bob/config/` on the main branch.

See the main branch's `AGENTS.md` for setup instructions.
