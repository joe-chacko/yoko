# Bob Documentation Branch

This branch contains intermediate documentation, analysis, and planning artifacts created during development with Bob Shell.

## Structure

- `test-plans/` - Test plans and testing strategies
- `analysis/` - Technical analysis and investigation notes
- `designs/` - Design documents and proposals

## Usage

This branch is checked out as a Git worktree in `.bob/docs/` on the main branch.

Developers can work on documentation here and selectively share it with the team by committing and pushing.

**Note:** Personal notes should remain in `.bob/notes/` (not tracked in git) for privacy.

See the main branch's `AGENTS.md` for setup instructions.
