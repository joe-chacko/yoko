# Bob Memory Branch

This branch contains shared team knowledge and memories for Bob Shell.

## Structure

- `AGENTS.md` - Main agent memory file with project conventions and preferences
- `team-preferences.md` - Team coding standards and practices (optional)
- `project-context.md` - Project-specific knowledge (optional)

## Usage

This branch is checked out as a Git worktree in `.bob/memory/` on the main branch.

The `AGENTS.md` file is automatically loaded by Bob Shell to provide context about team preferences and project conventions.

See the main branch's `AGENTS.md` for setup instructions.
